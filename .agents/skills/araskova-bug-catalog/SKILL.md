# Araskova Bug Catalog Skill
1. NEVER USE ORBITRON.
2. SplitFlapText: Sanitize glyph set to fixed-width alphanumeric characters.
3. WebGL / Canvas: Support light mode by inverting shard colors or supplying #fbf8f8 clearColor.
4. Focus Blocking: Use HTML inert attribute instead of aria-hidden when children retain focus.
5. Real Products: Only VIGIL, ARGUS, CERBERUS, AERIAL, AXIS, QR GOD. Never fabricate products.
