# Araskova De-Watermarking Playbook
1. Banned Dependencies: Purge @lovable.dev/vite-tanstack-config, lovable-tagger, and any dev taggers.
2. Native Vite Configuration: Use standard @tanstack/react-start/plugin/vite, nitro/vite, and @tailwindcss/vite.
3. Supply Chain: Remove third-party generator package bypasses from bunfig.toml.
4. Project Identity: Rename generic package.json names (tanstack_start_ts, my-app, vite-template) to araskova-<slug>.
5. Placeholders: Scan and purge YOUR_BING_VERIFICATION_KEY, YOUR_API_KEY, and dummy credentials.
6. Logging: Replace all raw console.log and console.error with createLogger from @/lib/logger.
